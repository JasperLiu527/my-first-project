# 💪 锻炼计划 App

一个纯前端的锻炼计划应用，无需安装任何依赖，用浏览器直接打开 `index.html` 即可使用（手机、电脑都适配，支持深色模式）。

## 功能

- **今日训练**：自动显示今天（周几）的训练内容，点击每一组打卡，实时显示完成进度；完成后一键保存到训练记录。
- **休息计时器**：完成一组后自动开始组间休息倒计时（60 秒 / 90 秒 / 2 分钟 / 3 分钟可选），时间到会提示音 + 震动。
- **每周计划**：为周一到周日分别设置训练重点和动作（组数、次数、重量），随时增删修改。
- **内置模板**：新手全身、推/拉/腿、上下肢分化、居家徒手，一键套用。
- **训练记录**：查看历史训练，统计累计次数、本周次数和连续训练周数。

所有数据保存在浏览器本地（localStorage），不会上传到任何服务器。

## 文件结构

- `index.html` — 页面结构
- `style.css` — 样式
- `app.js` — 应用逻辑
